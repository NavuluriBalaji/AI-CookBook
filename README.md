# 🧑‍🍳 **AI Recipe Genius**

> Your personalized culinary assistant, created by Navuluri Balaji.
## ✨ Introduction

**AI Recipe Genius** is a cutting-edge, AI-powered recipe generator that crafts unique meal ideas based on the ingredients you have on hand, your dietary restrictions, and your flavor preferences. This project leverages a large language model (LLM) fine-tuned on a vast dataset of recipes to offer a truly personalized cooking experience.

Whether you are looking for creative ways to use up leftover ingredients or need inspiration for a weeknight dinner, this AI cookbook eliminates food waste and sparks your culinary creativity.
## 🌟 Key Features

*   **Intelligent Recipe Generation:** Creates new recipes on demand based on user-specified ingredients and constraints.
*   **Dietary and Allergen Filters:** Generates recipes that respect dietary needs (e.g., vegetarian, vegan) and common allergens.
*   **Step-by-step Instructions:** Provides clear and easy-to-follow cooking instructions for each generated recipe.
*   **API for Developers:** A RESTful API is available for integrating the recipe generation functionality into other applications.

## 🛠️ Technology Stack

*   **Model:** A fine-tuned Large Language Model (LLM) for recipe generation.
*   **Frameworks:** PyTorch / TensorFlow
*   **Backend:** FastAPI for the API service.
*   **Frontend:** Streamlit for the interactive web interface.
*   **Libraries:** `requests`, `numpy`, `pandas`, `transformers`
*   **Containerization:** Docker for easy deployment.
*   **Agentic Frameworks:** CrewAI, nbagents, ADK, Langchain, Langgraph, Autogen
